# Complete Boolean evaluation receipts

The shared contract and first conservative private implementation are now
registered after the frozen v30 baseline and passed the v35 full Source gates
on both hosts. It follows the actual v23 state
observation without increasing a quota or deleting inspection/debt history.
Root owns ChannelAction/Core/provenance, frozen Source and the real expression
emitter; C owns the private producer, Source reader and replay refinement.

## First registered integration

The real expression emitter returns the actual operand observation token.
`check_is` emits a receipt only after a complete Normal pattern decision and
the actual evaluation ID, under the normal control guard before selection.
`source_event` remains an enclosing-call context locator: it is not an ordinary
call identity for `is` and does not prove completion. The independent reader
checks the unique whole-condition observation and frozen operand separately.

The first Source admission is intentionally finite: a real independent
function-header entry, or its first direct canonical `Concurrent::scope` call
with one actual lambda callback. Incoming named-caller prefixes, computed or
aliased scope callees, conditional callback calls, nested callback paths,
defaults and budget previews provide no truth. This classification uses real
Source/header/application/context links, not a mutable `declaration_probe`
eligibility flag. Existing execution-bound analysis additionally checks the
callback's minimum entry before the new proof is consulted.

The current carrier must have no reachable heap origins, snapshot nodes or
relations. Producer sets, nested Result/Option identities, tags and origins
are compared with the real frozen formal projection; the actual operand
observation preserves the complete received permissions and borrow evidence.
Capture names must refer to actual captured binders whose Source spans match
the formal/alias/projection path. Complex historical heap reads remain unknown.

Source control obligations are explicit. Only a first match arm with canonical
single-layer `Some(Name)` or `Some(_)` is admitted, and its real root Optional
identity must be implied by the receipt guard. Nested/refutable payload
patterns and later arms remain unknown, including legal earlier guarded or
partial arms. Preceding nontrivial calls, binding initializers and assignments
retain an unproved normal-completion obligation. Earlier callee/argument/tuple/
array siblings also retain their normal-completion obligations. A previous
assertion needs its actual Source builtin call, complete condition evaluation
and true Boolean control; it cannot be erased by widening a tag/receipt guard.

The first tag record is only extra temporal/physical consistency. Independently
reconstructed parent controls are still required if both that record and the
receipt are changed together. No Source theorem is manufactured from a
recorded constant, final duty flag, same span or matching type string.

Unknown receipts are skipped as proof events and do not split or delete cases.
A proved receipt refines only its active case with the actual Boolean ID; its
inactive case and all nine state components remain intact. No inspection,
return, custody, clone, queue, task or permission obligation is paid.

## Small shared representation

Propose one ChannelAction variant for the first pattern-only phase:

```rust
ConditionEvaluated {
    evaluation: ConditionEvaluationId,
    subject_expression: usize,
    subject: CopyValueSnapshot,
}
```

The enclosing ChannelMessageFact already supplies the actual event ID,
sequence, context, activation, task, allocation epoch, span, cause and guard.
Use the complete condition's span/cause/context. `source_event` is not a fake
ordinary call token for `is`; the exact subject expression index is emitted
by the real expression recorder. No `complete=true`, `trusted=true` or
`known_truth` flag is an authorization. Recorded constant is a consistency
claim; the independent Source reader reconstructs any usable truth itself.

EvaluationId is the primary physical identity of the complete condition.
The outer expression fact is emitted after `check_is` returns. Require its
unique actual InvocationExpression/ExpressionFact link to the same evaluation
ID, context, complete source span and cause ancestry. A span alone, first row,
surrounding callback or another evaluation of the same AST cannot substitute.
If direct full-condition expression indexing later proves necessary, Root
must add a real emitter/backfill protocol; it cannot reserve `len()` before
nested expressions have emitted their own rows.

## Producer ordering and actual operand token

`record_condition_evaluation` currently stores kind/context/span/cause,
constant and inspection evidence, then inserts the new ID into the value and
calls `channel_record_boolean_identity`. That last call changes the value's
true/false evidence and boolean-owner registry, not the current global Flow
guard. Known true still gets Bool(id,true); the false evidence becomes never.

Root proposes extracting the **same** expression emitter into
`expression_expected_observed() -> (Value, Option<usize>)`, with the existing
`expression_expected` and a new `expression_observed` as wrappers. Capture the
actual index at InvocationExpression/ExpressionFact emission. The traversal-
budget early return carries None, and cannot produce a receipt. No last-row,
span search, synthetic expression or new public arena is needed.

The private `check_is` sequence is:

1. Evaluate the subject through that observed emitter, preserving its real
   token and frozen subject value/provenance.
2. Evaluate the complete pattern operation under the normal existing rules.
   Subject Never or a PatternOutcome::Exit returns without a receipt.
3. After the complete normal decision, capture the normal completion control
   guard G, before choosing the Boolean continuation. It must not contain the
   new evaluation's own Boolean atom. Do not use a pre-subject entry guard if
   the subject/payload can terminate or perform effects.
4. Mint and record the new ConditionEvaluationId; a private return value from
   `record_condition_evaluation` can expose this actual ID to the producer.
5. Emit the receipt with G and the actual operand token/snapshot, before any
   enclosing assert/if selects true or false.

One TagTest head does not certify the complete `Ok|Err` operation, especially
for short-circuit alternatives or effectful payload patterns. No receipt may
be emitted for a preview, skipped callback, zero-entry loop or unresolved
evaluation just because its AST exists. Ordinary inspections before the first
send matter: eligibility cannot depend only on the private flow's currently
adopted business producer set. A relevant Result subject/actual operation
must retain its receipt before later transport.

Literal Boolean receipts are a later optional extension. The first phase
does not need to enlarge its contract beyond complete `check_is` operations.

## Independent Source proof

Before refining a case, require all of the following:

- Actual condition/context/source links and a unique whole-condition
  observation; the real callable owner must locate the frozen ExprKind::Is.
- The subject token references the actual operand observation in this context,
  and its span matches the operand AST within that condition. Its frozen type,
  causes, sources, producer identities and snapshot are consistent with the
  historical reception; final mutable heap/binding flags are not substitutes.
- The initial admitted truth is an independently resolved canonical Result
  subject with both canonical Ok and Err alternatives, each with an
  irrefutable wildcard payload. Constructor spelling alone is insufficient.
  Nominal impostors, aliases with unproved owners, payload equality tests,
  unknown subject types and incomplete/mismatched Source remain unproved.
- Callback/default/caller/closure ancestry, actual minimum entry and evaluation
  completion are proved using the same conservative Source requirements as
  inspections. A declaration or one hypothetical loop body is not execution.

Subject Source typing/resolution must be grounded in the actual typed source
and its lexical/instantiation environment. Do not manufacture that premise
from the receipt's own type string or recorded constant. The concrete E508
subject is `inner`, projected through Some from the declared
`Option<Result<int,str>>` formal; its real capture/argument/path still needs
the independent context and snapshot links. Required missing witnesses stay
unknown rather than restoring data erased by an annotation or wrapper.

Payload effects, unit-only Ok(), type tests, guarded patterns and compound
Boolean operations are outside the first wildcard phase unless Root approves
additional complete-evaluation evidence. Unknown reconstruction provides no
truth constraint. A contradiction with a claimed recorded constant is an
inconsistency, not permission to choose a convenient interpretation.

### Concrete unregistered Source reader and its limits

`channel_condition_source.rs.pending` now implements a Source-only reader. It
explicitly takes `&Program`, the actual function header, an independently
selected lexical lambda path and the complete condition span. It does not read
`Value.ty`, `ConditionEvaluation.constant`, final `BindingInfo` values or the
producer's constructor registry. A result includes the real formal parameter
position/binder, capture lambda spans/names, Some-payload pattern occurrence,
immutable alias and ordinary field projection steps, and the actual operand
and complete condition spans.

The reader requires a unique, structurally identical function header/body in
the frozen Program. It reconstructs global, signature-where, block-where and
local declaration shadows, generic names, sequential value bindings and
actual match binders. Canonical type resolution checks real declaration/value
shadows before treating a name as a Prelude builtin. Unqualified constructors
also need an unshadowed actual value namespace and a canonical expected Result
subject. Explicit Prelude constructors do not turn a nominal Result into the
standard Result. Unresolved globs remain unknown.

The admitted subset starts with read parameters, immutable let/view aliases,
typed tuple/record field paths, lexical captures and canonical `Some(inner)`
match projection. It does not infer a Source root from a local type annotation,
reassignable binding, arbitrary call, clone, inferred final type or constructor
spelling. Type aliases/computations, nested named roots, loops, handlers,
default-expression contexts and additional pattern effects remain pending.
It uses a caller-owned remaining work counter; syntax/declaration visits and
environment/source-shape copying all consume that same counter. An exact
remaining-budget test passes at the measured work and refuses one unit less.
There is no fresh quota or fallback.

For the unchanged E508 fixture, the component reconstructs the first
`inner is Ok(_)|Err(_)` through `consume` formal position 1 (`other`), the real
scope lambda capture and `Some(inner)`. The second same-spelling predicate
after `Channel::recv` remains **None**: this subset has no independently
resolved Source return schema for that actual receive. Passing the first
component check does not support the entire source or justify constraining
the second evaluation.

The proposed shared Source premise is
`SemanticFacts.source_program: Option<Arc<Program>>`, captured from the actual
frozen executable syntax by normal analysis. Root owns registration and the
checks against the genuine analyzed syntax. Absence cannot default to builtin
names when a receipt needs Source proof. Keeping the existing `solved_facts`
API does not make the producer's mutable declaration registry an independent
Source premise. Core needs the solved receipt references, not a second copy
of the full AST.

The pending reader does **not** establish the supplied lambda path's physical
owner IDs, an actual creation/call ancestry, normal completion, minimum entry,
operand observation identity or frozen snapshot consistency. Integration
must prove those separately, including the real closure object's capture
creation context and the root parameter reception. Two observations of one
lambda body or two same-span parameters cannot exchange these witnesses.

## Local replay refinement, not global substitution

Treat the receipt as an actual guarded observation. Existing replay first
splits A into active=A AND G and inactive=A AND NOT G. After independent proof
of the **complete** operation's truth, refine only the active case:

```
active.guard = active.guard AND Boolean(evaluation, proven_truth)
```

The inactive case retains its original state and guard. An expression not
evaluated on a path supplies no truth there. Later event complements naturally
contradict the locally constrained Boolean, eliminating only the impossible
post-evaluation alternative. Do not globally replace all Bool(id,true) atoms
with true or filter every opposite literal using the unvalidated constant.

This action does not change custody, owners, queues, inspected/returned sets,
task clocks, closed anchors or executed transport IDs. In particular, a total
outer Result test can prove its Boolean value true without inspecting nested
Results, paying a clone's debt, choosing Ok over Err, proving optional presence
or granting mutable/shared authority. Existing actual inspection receipts keep
their separate duties. No native instruction or runtime ABI action is added;
Core provenance preserves the proof record.

## Acceptance and adversarial gates

Keep existing guard laws, Source selector mutations, formal independence,
clone debt, ordinary Result-only and zero/unknown callback controls. Add:

- Delete a complete receipt, replace it with a single TagTest head, relocate
  it before completion, or omit the actual subject/condition observation.
- Change evaluation/operand ID, caller/closure/default context, source owner,
  sequence, guard, cause, snapshot or constructor owner; same-span rows cannot
  become another evaluation's receipt. Self-Boolean guards are circular.
- Forge constant true for a non-exhaustive Ok-only predicate or nominal
  same-spelling constructors. Unknown/private callbacks cannot acquire entry.
- Exercise conditional non-evaluation, normal short circuit and abnormal
  subject/payload evaluation. Unexecuted cases retain their debt/history.
- Confirm complete outer tests do not pay inner or cloned Result producers,
  and that readonly detached scalar copies remain distinct from later writes
  to a captured mutable Boolean cell.

Use a small independent concrete model for guarded receipt execution: only
states where the receipt actually executes gain its Boolean equality. Compare
unpaid-debt and inactive outcomes, not just Boolean truth tables.

Only after the unchanged entire E508 source actually passes Session/Core may
its pending positive gate and fresh native execution be registered. If the
case bound moves or persists, retain the new exact NI and measure the next
missing proof. Increasing 256, clearing inspection sets or discarding completed
history is not part of this contract.
