# 15. Host Interoperability and ABI (Reserved)

This chapter is reserved for future host interoperability, foreign function interfaces (FFI), and external system application binary interface (ABI) specifications.

---

## 1. Specification Status

External host contract declarations (`decl`), boundary bridging modules, and ECMAScript/TypeScript compilation target mappings are excluded from the current language specification scope.

Foreign function interfaces (FFI) and native platform ABI bindings are deferred to subsequent design revisions. Conforming implementations MUST NOT rely on experimental or unstandardized host declaration extensions.
